# სიახლეები WordPress-იდან

საჯარო საიტი: Next.js. ადმინისტრაცია: არსებული WordPress. ამ ეტაპზე WordPress-ის პარამეტრები და პოსტები არ შეცვლილა.

## გამოქვეყნება
1. WordPress-ში გახსენით Posts → Add New.
2. ჩაწერეთ ქართული სათაური, ძირითადი ტექსტი და მოკლე excerpt; მიუთითეთ Featured Image და ქართული alt ტექსტი.
3. გამოიყენეთ სემანტიკური H2/H3 სათაურები, აბზაცები, სიები და ცხრილები. HTML-ში სკრიპტები, iframe, ფორმები და inline სტილები Next.js-ზე არ გადადის.
4. გამოაქვეყნეთ Publish-ით. Draft, დაცული და მომავლის თარიღიანი ჩანაწერები არ გამოჩნდება.
5. შეამოწმეთ `/news` და `/news/თქვენი-slug`.

წაკითხვის წყარო: `WORDPRESS_API_BASE_URL`, ნაგულისხმევად `https://bitrixgeorgia.ge/wp-json/wp/v2/`. WordPress-ის პოსტის ბმული ადმინისტრაციაში ჯერ კიდევ ძველ საიტზე მიდის; ახალი frontend-ის ნახვისთვის გამოიყენეთ ახალი `/news/slug` მისამართი.

## კატეგორიები
| WordPress slug | საიტზე |
| --- | --- |
| `guides` ან არსებული `uncategorized` | პრაქტიკული გზამკვლევები |
| `bitrix24-news` | Bitrix24-ის სიახლეები |
| `company-news` | კომპანიის ამბები |

კატეგორიების შექმნა WordPress-ში ჯერ არ შესრულებულა. სხვა კატეგორიების პოსტები ყველა სტატიის სიაში ჩანს „სტატიები“ ნიშნით. აღმოჩენილი ორი ძველი ინგლისური სადემონსტრაციო პოსტი (23202, 6200) მხოლოდ ახალი საიტის შედეგებიდანაა გამორიცხული; WordPress-იდან არ წაშლილა.

## განახლების დრო
მონაცემებს Next.js Data Cache ინახავს 300 წამით. ვადის გასვლის შემდეგ გვერდზე მომდევნო მოთხოვნა იწყებს განახლებას; პირველი სტუმარი შეიძლება წინა მონაცემს ხედავდეს. ეს არ არის ყოველ 5 წუთში გაშვებული cron და არც გამოქვეყნების ზუსტად ხუთწუთიანი გარანტია. წყაროს შეფერხებისას გამოიყენება ხელმისაწვდომი ქეში ან ქართულენოვანი შეცდომის მდგომარეობა.

მომზადებულია მყისიერი განახლების endpoint: `POST /api/revalidate`, ჰედერი `Authorization: Bearer <secret>`. Vercel-ზე `WORDPRESS_REVALIDATE_SECRET` უნდა შეიცავდეს მინიმუმ 32 სიმბოლოს. გასაღები უნდა იყოს მხოლოდ სერვერებზე; არ გამოიყენოთ URL query ან ბრაუზერი. გაუმართავი კონფიგურაცია აბრუნებს 503-ს, არასწორი გასაღები — 401-ს, წარმატებული ქეშის გაუქმება — 200-ს.

WordPress webhook ჯერ არ არის დაყენებული და secret არ არის შექმნილი. მის დასაკავშირებლად საჭიროა მფლობელის მითითება მოქმედ WordPress-ში ცვლილებაზე; მანამდე ჩვეულებრივი პერიოდული განახლება მუშაობს საჯარო API-ით.

## დომენის გადატანამდე
WordPress უნდა დარჩეს ცალკე HTTPS მისამართზე (მაგალითად `cms.bitrixgeorgia.ge`). ჯერ უნდა შემოწმდეს ადმინისტრაცია, REST API და მედიის ბმულები, შემდეგ განახლდეს Vercel-ის `WORDPRESS_API_BASE_URL`. წინააღმდეგ შემთხვევაში ძირითადი დომენის Next.js-ზე გადატანა კონტენტის წყაროს გათიშავს. DNS-ის ცვლილება ცალკე ეტაპია.
