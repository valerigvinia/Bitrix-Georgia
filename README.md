# Bitrix Georgia

ქართული Bitrix24 სერვისების მრავალგვერდიანი Next.js / TypeScript საიტი. სიახლეების წყარო და ადმინისტრაცია: https://bitrixgeorgia.ge/ . დროებითი მისამართი: https://bitrix-georgia.vercel.app . დომენის მიგრაცია ჯერ არ სრულდება.

## გაშვება
Node.js 24 LTS და npm.

```sh
npm ci
npm run dev
```

http://localhost:3000

```sh
npm run build
npm run typecheck
npm test
npm start
```

## სტრუქტურა
```text
src/app/           მარშრუტები, layout და გლობალური სტილები
src/content/       ქართული კონტენტი
src/components/    საერთო UI, ნავიგაცია, ფასები და ფორმა
src/lib/           WordPress, HTML-ის გაწმენდა, ფასების წაკითხვა
tests/             ფასებისა და კონტენტის უსაფრთხოების ტესტები
docs/brand/        დაცული ბრენდბუქი
docs/              გეგმა, გადაწყვეტილებები, ფასები, deployment
assets/reference/  ლოკალური საცნობარო ფაილები; Git-ში არ შედის
.github/workflows/ ავტომატური შემოწმება
AGENTS.md          დაცული სამუშაო წესები
```

`.env.example` არის კონფიგურაციის შაბლონი; რეალური საიდუმლოებები Git-ში არ ჩაიწეროს. ჩვეულებრივი წაკითხვა მუშაობს საჯარო წყაროებით API გასაღებების გარეშე.
